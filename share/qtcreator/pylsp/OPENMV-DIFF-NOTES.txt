OpenMV modifications to the embedded pylsp bundle
==================================================

The bundles in this directory (windows/, mac/, mac-aarch64/, linux-x86_64/,
linux-arm64/) are kept EXACTLY as downloaded. Do not edit them.

OpenMV's changes live in openmv/sitecustomize.py. The IDE puts openmv/ first on
the language server's PYTHONPATH (src/plugins/python/pythonlanguageclient.cpp,
PyLSInterface::startImpl), so Python runs it as `sitecustomize` when the server
starts, and it patches Jedi in memory. The build copies openmv/ with the
bundles (share/qtcreator/CMakeLists.txt).

Updating a bundle
-----------------
1. Replace the platform folder(s) with the new download.
2. Run the checks with a desktop Python:

       python share/qtcreator/pylsp/openmv/check_patches.py

   Every bundle should report "OK". A failure names the behavior that broke;
   a patch whose target Jedi reshaped also prints "OpenMV IDE pylsp patches:
   <name> not applied" -- adjust that patch in sitecustomize.py to the new Jedi.
3. Restart OpenMV IDE (pylsp keeps Jedi loaded while it runs).

The patches (Jedi 0.19.1)
-------------------------
OpenMV's stubs (share/qtcreator/html/stubs) describe the camera's MicroPython
API. Left alone, Jedi treats a stub as a partial description of a desktop module
of the same name and fills in the rest from it, and it emulates CPython behavior
MicroPython doesn't have; both made the editor offer code the camera can't run
(e.g. "AttributeError: module 're' has no attribute 'findall'", forum 11904).

  1. No name mangling (ClassFilter._access_possible): Jedi hid `__name` class
     members from outside the class, as CPython mangles them; MicroPython
     doesn't, so csi.CSI().__read_reg/__write_reg must complete.
  2. Stub-only completion (jedi.api.completion.complete_trailer): no names from
     the desktop module behind a stub (re.findall, json.JSONDecoder).
  3. Stubs first (Script.goto / Script.infer prefer_stubs): go to definition,
     hover and help land on the stub, not the desktop source.
  4. Stub docstrings (TreeNameDefinition.py__doc__): a stub's own docstring wins;
     the implementation's only when the stub has none.
  5. Stub submodules (StubModuleValue.sub_modules_dict): only the stub's own (not
     re's _compiler, _parser...).

Modules without an OpenMV stub (tkinter...) still complete from desktop Python.

History: patch 1 was first made (2026-07-09), and patches 2-5 briefly
(2026-10-20), by editing the bundles' Jedi files; both moved here on 2026-10-20
and the bundles were restored to the original wheels' files.

Known, harmless: every bundle lacks jedi/third_party/django-stubs/django-stubs/
core/ (75 files), most likely dropped by a git ignore rule for "core"; it only
affects Django completion.
